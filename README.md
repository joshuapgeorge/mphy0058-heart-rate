# MPHY0058 Group Coursework: Heart Rate from Optical Sensor and Video

Estimating heart rate from a PPG optical sensor signal (CSV) and a video of a finger on a phone camera.

## Team
- Joshua Perumpampallil (GitHub: Joshuapgeorge)

## How to run
1. `pip install -r requirements.txt`
2. Put `video_of_finger.MOV` in `data/` (not tracked by Git because of its size)
3. Open `heart_rate_analysis.ipynb` and run all cells
